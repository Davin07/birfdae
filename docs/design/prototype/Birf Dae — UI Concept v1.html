Libra
What changed, and why. Palette moves from teal-on-black glassmorphism to a terracotta tonal system (HCT-derived, every pair clears WCAG AA in light and dark). Type goes from FontFamily.Default on every style to Fraunces for display and Figtree for body. The list, calendar and settings screens stop competing with the celebratory moment for attention.
